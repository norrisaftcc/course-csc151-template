Terms used on this page

Spine
The fixed unit sequence: Module 0 through Module 8, plus the Appendix. The delivery platform requires exactly this count.
Verifier
scripts/verify.sh — the course’s own check script. It compiles every example, runs it, and compares the output to the recording. One compile check plus one run check per example gives the 42 total.
.expected recording
A file holding an example program’s exact correct output, generated from a real run. The verifier replays the program and diffs against it.
Input fixture (.stdin)
A file of typed-in input for examples that read from the keyboard, so the verifier can run them unattended.
Getting on The Bus
Module 0’s title — a sports idiom meaning “joining the team and its way of working.” The course glosses every idiom this way; it is one of its writing rules.

Source of truth for the sequence: docs/course-map.md. This page is a snapshot; regenerate it rather than editing the numbers. It is one self-contained file with no network requests, so it opens from a local copy of the repository in any browser.
